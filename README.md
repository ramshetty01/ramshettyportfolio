# Ram Shetty portfolio

A static, responsive portfolio built with HTML and CSS. Open `index.html` in a browser or serve the directory with:

```sh
python3 -m http.server 8000
```

The project descriptions are based on the public repositories at [github.com/ramshetty01](https://github.com/ramshetty01). Update `index.html` to add employment history, contact details, or additional projects. No build step or dependencies are required.
